# Mockups — nassauTickets

Esta pasta contém os mockups das principais telas do sistema nassauTickets.

## Telas do sistema

O projeto possui os seguintes mockups:

- Tela de Login
- Tela do Totem
- Tela do Painel de Chamadas
- Tela do Atendente

## Objetivo

Os mockups têm como objetivo representar visualmente a interface do sistema antes da implementação, facilitando a compreensão das funcionalidades e da experiência de uso.

## Principais funcionalidades representadas

### Totem

Permite ao cliente emitir sua senha de atendimento.

### Painel de Chamadas

Exibe as senhas chamadas e o respectivo guichê.

### Atendente

Permite ao atendente chamar a próxima senha, chamar novamente, iniciar o atendimento e finalizar o atendimento.

### Login

Permite a autenticação do atendente para acessar o sistema.

## Organização

Cada arquivo desta pasta representa uma tela ou conjunto de telas do sistema.
