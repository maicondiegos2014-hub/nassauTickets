# Paleta de Cores - nassauTickets

A paleta de cores do nassauTickets foi definida para proporcionar uma
interface organizada, moderna e de fácil compreensão.

| Cor | Código HEX | Utilização |
|---|---|---|
| Azul principal | #2563EB | Botões, elementos principais e identidade |
| Azul escuro | #1E3A8A | Títulos e elementos de destaque |
| Branco | #FFFFFF | Fundos e contraste |
| Cinza claro | #F3F4F6 | Fundos secundários |
| Cinza escuro | #1F2937 | Textos principais |
| Verde | #16A34A | Confirmações e status positivo |
| Vermelho | #DC2626 | Alertas e erros |

## Cores principais

### Azul principal
#2563EB

Representa tecnologia, organização e confiança.

### Azul escuro
#1E3A8A

Utilizado para proporcionar contraste e destacar informações importantes.

### Branco
#FFFFFF

Utilizado principalmente em fundos e áreas de conteúdo.

### Cinza claro
#F3F4F6

Utilizado para separar áreas da interface e criar fundos secundários.

### Cinza escuro
#1F2937

Utilizado principalmente para textos.

### Verde
#16A34A

Utilizado para indicar situações positivas, como atendimento concluído.

### Vermelho
#DC2626

Utilizado para alertas, erros e situações que exigem atenção.
